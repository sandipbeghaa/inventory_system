# Live Inventory Manager

A simple interactive inventory management desktop application built with Python and Tkinter. You can add, update, or remove items through a clean graphical interface, and the live table on screen updates immediately.

## What's Inside

- **Add Items:** Enter item details through input fields and add them directly to the inventory list.
- **Update & Remove Items:** Select existing items to edit their quantities/details or remove them from the system.
- **Live Table View:** Built with Tkinter's table widget (`Treeview`) so every change shows up immediately on screen without restarting the app.
- **Zero External Dependencies:** Runs using Python's built-in standard library (`tkinter`).

## Built With

- Python 3
- Tkinter (Python GUI library)

## How to Run It on Your Computer

1. Make sure you have **Python 3** installed on your computer.
2. Clone or download this repository:
   ```bash
   git clone https://github.com/sandipbeghaa/inventory_system
   ```
3. Open the project folder and run the Python script:
   ```bash
   cd inventory_system
   python inventory_system.py
   ```
